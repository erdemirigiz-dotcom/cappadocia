# Cappadocia — demo business website

A finished single-page demo site for a Cappadocia hospitality business, built by Demir /
Iron Vision Tools as a showcase of small-business web work: static HTML/CSS,
self-hosted fonts, no tracking, fast on mobile.

- 11 languages, switchable in the UI
- Self-hosted fonts and assets (no third-party CDN calls)
- Booking form wired to a demo backend endpoint (configurable, see `docs/PRD.md`)
- Optimized page weight (~3.5 MB, down from ~10 MB)

Live demo: https://cappadocia-demo.vercel.app
More: https://ironvisiontools.com
Product notes: [docs/PRD.md](docs/PRD.md)
